# Solstice Cipher

Solstice Cipher is a tiny browser game for the DEV June Solstice Game Jam.

Theme fit:

- Solstice: balance the light meter while moving through the maze.
- Light and darkness: too much of either destabilizes the route.
- Alan Turing: collect cipher sparks to unlock the gate.

Run locally:

```bash
npm test
npm run serve
```

Then open `http://localhost:4173`.
